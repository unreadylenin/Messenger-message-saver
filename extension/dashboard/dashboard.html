    How it works

    • Saving. While a Facebook or Messenger tab is open, the extension keeps a private copy of messages: from Messenger's own data for normal chats, and from what is shown on screen for every chat (including end-to-end encrypted ones). Everything stays on this computer.
    • Unsent messages. When someone unsends, Messenger shows “… unsent a message”. The saved original appears right under it, in the Unsent & deleted tab, and as a desktop alert.
    • Edited messages. Earlier versions are kept and shown under the edited message.
    • Unseen. “Seen” is not sent when you read. In normal chats the read marker is held back; in encrypted chats this works through Strong mode, which tells Messenger the window is not focused. Check it once with a friend.

    Limits

    • A message can only be recovered if it reached this browser before it was unsent: Messenger must have been open in a tab (a chat pop-up or the Messages page). Messages unsent while Facebook was closed cannot be recovered.
    • In end-to-end encrypted chats the message must have been shown on screen at least once (the chat pop-up or chat page was open), or have arrived as a Messenger notification.
    • “Typing…” can only be hidden in normal chats.
    • Facebook changes its website often. If something stops working, check Settings → Diagnostics.

    Privacy

    No data leaves your computer. The extension has no servers and sends nothing anywhere. Uninstalling it deletes everything it saved.
